Inkubio API

Inkubio Climate API

Tämä rajapinta tarjoaa reaaliaikaista ja historiallista ilmanlaatutietoa Inkubion kiltahuoneelta. Data sisältää lämpötilan, ilmankosteuden ja hiilidioksidipitoisuuden (CO2).

GET /ilmanlaatu

Kuvaus

Hakee ilmanlaatumittauksia valitulta aikaväliltä. Jos parametreja ei anneta, palauttaa oletuksena viimeisimmän 24 tunnin mittaukset. Data pisteitä on minuutin välein.

Parametrit

Nimi Tyyppi Kuvaus
start string (Suositeltu) Haun alkuaika ISO 8601 -muodossa (esim. 2026-01-18T08:00).
end string (Valinnainen) Haun loppuaika. Jos jätetään tyhjäksi, haetaan nykyhetkeen asti.

Esimerkkipyyntö

curl "https://api.inkubio.fi/ilmanlaatu?start=2026-01-18T10:00&end=2026-01-18T10:02"

Esimerkkivastaus

[
  {
    "timestamp": "2026-01-18T10:00:22+02:00",
    "temperature": 22.07,
    "humidity": 25.06,
    "co2": 687
  },
  {
    "timestamp": "2026-01-18T10:01:22+02:00",
    "temperature": 22.07,
    "humidity": 25.12,
    "co2": 687
  }
]
